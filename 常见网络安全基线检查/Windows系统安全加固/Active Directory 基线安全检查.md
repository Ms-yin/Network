## 1.引言
本文档旨在提供一份 Active Directory（AD）的安全基线检查指南，帮助组织识别和解决潜在的安全问题，确保 AD 基础架构的安全性和稳定性。

## 2.适用范围
适用于所有使用 Active Directory 服务的组织，作为编制安全审计、加固操作的参考依据。

## 3.缩略语
+ AD：Active Directory
+ DC：域控制器
+ DFL：域功能级别
+ FFL：林功能级别
+ GPO：组策略对象
+ SPN：服务主体名称

## 4.安全基线要求项命名规则
安全基线要求项是安全基线的最小单位，对应一个基本的可执行的安全规范明细。命名规则为：“安全基线 – 一级分类 – 二级分类 – 类型编号 – 明细编号”，例如：SBL-AD-User-01-01，表示“安全基线 – AD 类 – 用户管理 – 问题账户 – 无效账户”。

## 5.文档使用说明
### 5.1 适用环境
+ Windows Server 2012 R2 及以上版本
+ PowerShell 5.0 及以上版本
+ 配备 Active Directory 和 Group Policy PowerShell 模块

### 5.2 操作指引
+ 以具备 AD 用户权限的账户运行Invoke-TrimarcADChecks.ps1脚本。
+ 脚本执行后，部分结果会显示在屏幕上，同时所有数据会被保存到C:\temp\Trimarc-ADReports文件夹中的csv和text文件里。
+ 定期（建议每月）执行脚本，以持续监控AD安全状态。

### 5.3 注意事项
+ 脚本适用于单个AD林的检查，在多域环境中可能无法捕获跨域数据。
+ 脚本执行前，请确保已安装并配置好所需的PowerShell模块。
+ 执行脚本前，请备份相关系统和数据，以防出现意外情况。
